# Repository conventions

- Keep commit messages short, simple, and meaningful. Describe the change, for example `Add family templates` or `Clarify transfer hypothesis`.
- Keep one JSON record per original problem and preserve the agreed template fields.
- Retain source statements and approaches; document corrections in the analysis.
- Treat schema validation and mathematical review as separate checks. Never infer expert approval from a merge.
- Keep proposed research, completed experiments, and measured results clearly distinguished.
